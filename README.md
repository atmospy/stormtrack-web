# StormTrack Web

Fast, interactive weather & storm-tracking web app (windy.com-style, storm-analysis first).
Powered by the [`stormtrack`](https://github.com/atmospy/stormtrack) library.

- **Plan:** [`docs/PLAN.md`](docs/PLAN.md) · **Data contracts:** [`docs/CONTRACTS.md`](docs/CONTRACTS.md)
- `apps/web` SvelteKit app · `packages/wind-layer` WebGL wind layer · `services/ingest` data jobs ·
  `services/api` FastAPI · `supabase` auth/DB · `public-data` generated data products (not committed)

Status: M0 (foundations) in progress.
